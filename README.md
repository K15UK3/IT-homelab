# IT Homelab

Documenting my hands-on journey into IT — built this from scratch while transitioning careers into Help Desk / Desktop Support.

## What this is

A home virtualization server (homelab) I'm using to actually learn IT concepts by doing, not just reading about them. This repo tracks the real troubleshooting, decisions, and mistakes along the way — not just the polished end result.

## Current setup

- **Hardware**: AMD Ryzen 7 5700G, 32GB RAM, 1TB NVMe
- **Hypervisor**: Proxmox VE 9.2
